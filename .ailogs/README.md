# AI Project Logs

These files are the concise source of truth for future AI sessions. Read `STATE.md` first; read the other log files only when needed.

Before finishing any task, update the relevant logs:
- Rewrite `STATE.md` with the current snapshot; keep it to about 60 lines or fewer.
- Add one line to `CHANGELOG.md` in the format `YYYY-MM-DD | area | what | files touched`.
- Record bug → root cause → fix entries in `FIXES.md` when fixing bugs.
- Update feature status in `FEATURES.md`.
- Add a short note to `sessions/YYYY-MM-DD.md`.

When `CHANGELOG.md` grows beyond about 200 lines, summarize older entries into `.ailogs/archive/`.
