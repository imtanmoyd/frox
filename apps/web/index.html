More capable, still on your machine.

Run the Python engine on your computer for provider routing and local SQLite chat memory. It only receives the message you choose to send—not the page you’re browsing.

PRIVACY THAT STARTS WITH CHOICE

Your browser stays yours.

Frox doesn’t read or send page content automatically. When you ask a cloud AI, your message goes to the provider you configured. Or use a local model with Ollama. You’re in control.

  2. 2 Build with npm run build.
